# CampusHire

A full-stack job portal connecting students with recruiters.

## 1. Student Features
- Student signup and login
- Browse available jobs
- Search and filter jobs
- Apply for jobs
- Submit resume link
- Track application status

## 2. Recruiter Features
- Recruiter signup and login
- Create job postings
- Edit job postings
- Close job postings
- View applicants
- Update application status

## 3. Application Status
- Applied
- Shortlisted
- Rejected

## 4. Technology Stack
- React
- Python
- FastAPI
- PostgreSQL

## 5. Future Improvements
- Email notifications
- Job recommendations
- Application analytics
